本週工作週報：GAPGen 論文重構定稿與研究資產工程化

日期：2026-08-14

一、本週整體進展
- 主導完成論文核心重新定位，將題目升級為「Beyond Style Consistency: Gameplay-Consistent Generation of Game Asset Packs」，並確立系統品牌 GAPGen，把研究主軸從業界常見的「視覺一致性」突破性地拉高到更關鍵的「玩法一致性」，顯著提升論文獨特性與投稿競爭力
- 獨立完成從零到一的研究資產整併，單次提交涵蓋 300 個檔案、逾 11,000 行新增，把原本散落的實驗與素材全面工程化、可追溯，交付效率超前既定進度
- 重整專案根目錄 README 為 GAPGen 論文入口，Demo 系統文件獨立至 godot_demo/，對外建立一致且高辨識度的研究形象

二、論文全篇重構與精修
- 依新主軸逐節 re-framing，Abstract、Introduction、Related Work、Task、Method、Experiments、Conclusion 全面對齊玩法一致性論述，claim 與 evidence 一一對應，論證嚴謹度明顯強化
- 收斂系統敘事為三階段（ontology 規劃、雙參考一致性生成、雙軸驗證），主動移除冗餘章節，使核心貢獻更聚焦、更具說服力
- 全文精簡並統一術語，以圖檔取代 TikZ 系統圖，嚴格移除深澀詞彙與重複段落，整體可讀性大幅改善

三、評測自動化與可信度強化
- 建立 auto_eval、critic_backfill、research_ablation、research_multi_theme、research_retrospective 等腳本，把消融流程一鍵化，明顯降低重複人工成本
- 導入具方法論價值的跨模型評測設計，以 GPT-4o 評判 Gemini 生成結果、避免自評循環，並以 DINOv2 cohesion 作為與模型無關的佐證，強化結果可信度
- 完成 Fruit 三種子消融與 Pet/Ocean 延伸生成，以可量化數據證實 critic 能有效重新分配人工檢查摩擦，而非一味衝高通過率

四、與 AI 協作解決的關鍵挑戰
- 主動發現並修正 contribution 與內文不一致的風險，將未經人體實證的宣稱改為證據支持的跨模型評測敘事，避免過度宣稱
- 逐一排除刪節後殘留的 dangling reference 與跨章節用語不一致，確保全文一次到位、品質穩定

五、下週重點與展望
- 部署人類評測問卷、招募 n≥6 受試者，將 Human table 由 pending 補實，形成完整證據鏈
- 補齊作者資訊與致謝，完成 camera-ready 級 polish
- 目標讓 GAPGen 成為可對外展示的旗艦研究，並延伸為橫跨多遊戲類型的高影響力通用素材生成框架
