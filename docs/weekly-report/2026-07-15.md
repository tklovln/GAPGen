本週工作週報：AI 美術生成管線品質提升與 Google Cloud Day 參展

日期：2026-07-15

一、核心績效亮點
- 主導 AI 美術生成管線的品質評審重構，將整批生成的畫風一致性與良率大幅提升，顯著減少人工挑圖與重生所需的時間與人力成本
- 建立多道自動化品質閘門，讓不合格的美術在生成階段即被攔截，降低後段人工審核與返工成本，提升整體產出效率
- 代表團隊參與 Google Cloud Day，對外展示研究成果與產品 Demo，協助參展、現場測試、成果報告與產品推廣，擴大專案的外部能見度與影響力

二、Google Cloud Day 參展與產品推廣
- 協助籌備並參與 Google Cloud Day，於現場展示 AI 美術生成管線的研究成果與實際 Demo
- 負責現場產品測試與問題即時排除，確保 Demo 穩定順暢
- 進行成果報告與技術說明，向與會者推廣產品價值與應用場景
- 蒐集現場回饋，作為後續產品優化方向的參考

三、統一畫風與評審重構
- 將評審機制改為整批統一畫風，移除舊有分類判斷邏輯，讓不同物件維持一致調性
- 新增合理性評分，自動檢查物件比例與輪廓是否正常
- 新增去背完整度檢查，用棋盤格底自動揪出破洞與毛邊
- 通過門檻由 7 提高到 8 並集中統一管理，整體品質標準更嚴謹
- 評審模型升級，判斷更準確

四、生成硬規則與去背後處理
- 導入生成硬規則，禁止描邊墨線、要求填滿畫框，並拒絕過細或碎片狀的圖
- 強化去背後處理，能自動移除破洞、同時保留主體同色高光，避免誤刪
- 於生成階段就禁止在主體內使用去背色，從源頭減少去背瑕疵

五、背景生成品質閘門
- 針對棋盤背景新增專屬規則，禁止畫出格子、磁磚與棋盤，改要求柔和低對比的背景
- 背景改用專屬品質評分與通過標準，解決背景常被塞入破碎格子的問題

六、漸進階段物件自動化
- 新增自動偵測「同一物件不同階段」的功能，由模型從檔名與玩法功能自動判斷，不再只依賴手動標記
- 支援無數字級數物件的階段排序，並依完整到破損的順序驅動生成

七、穩定性與擴充
- 新增 API 與生圖逾時重試機制，提升批次生成的穩定度
- 新增繩網障礙物並簡化道具外觀
- 主題展開改為可套用於任何物件、支援批次重試與跨次快取合併
