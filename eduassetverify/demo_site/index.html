Overview

An image that looks right can still teach the wrong concept, such as a fraction drawn with unequal parts. Vision-language model (VLM) judges return holistic verdicts that carry no checkable evidence. EduAssetVerify separates perception from judgment: a VLM only reports what an image contains, without seeing the expected answer; deterministic operators measure its geometry; and three-valued rules decide each constraint, abstaining instead of guessing.

This page shows the outputs behind the paper: one test asset through every module, the counterfactual pairs, the result tables, and all 900 test assets with every verdict of every pass.

About these results

  • The assets are procedurally rendered benchmark images, not outputs of an image generator. Before any verifier ran, an independent script recomputed every label from the pixels; an item was kept only if both answers agreed.
  • The benchmark has 1,020 images: 120 for development, which fixed prompts and thresholds, and 900 for testing under four conditions (in-domain, unseen templates, two-operator errors, and four unseen styles).
  • Verdicts and reports are read from the experiment records of the paper (three independent passes per configuration and backbone); the judges' answers are read from the response cache of the same runs. No human rater was involved.
  • Once abstentions count as errors, every judge is more accurate than EduAssetVerify under Gemini 3.5 Flash, and EduAssetVerify is more accurate than every judge under Claude Sonnet 5.
  • The rule-only validator, which uses the same evidence without the semantic verifier and abstention, also accepted no violated asset and was more accurate than the full method under both backbones: on this benchmark the semantic verifier showed no measurable benefit, and abstention prevented no false acceptance but turned false rejections into reviews.
